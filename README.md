Marbella Run is an offline crime game set in a sun-soaked coastal city. Explore on foot or in stolen cars, take on eight story missions and side jobs, and outrun the police as your wanted level climbs to five stars.

## Run it

From the repository root with Node.js 22, run:

```sh
node serve.ts
```

Open [http://localhost:8080](http://localhost:8080) in desktop Chrome.
